# Time Series: Detecting Anomalies and Making Predictions
This project, provides a comprehensive approach to time series analysis, focusing on anomaly detection and predictive modeling. Using advanced machine learning techniques, we explore key concepts such as data smoothing, decomposition, and forecasting to extract meaningful insights from temporal data.

Key Features
✔ Data Distribution Analysis – Visualize trends and patterns using statistical plots.
✔ Moving Average Extraction – Smooth time series data to reduce noise.
✔ Anomaly Detection – Identify unusual patterns and outliers over time.
✔ Time Series Decomposition – Break down data into trend, seasonality, and residuals.
✔ Forecasting Model – Predict future values using machine learning.

Techniques Applied
📊 Exploratory Data Analysis (EDA) – Understand data structure and behavior.
📈 Moving Averages & Smoothing – Enhance data clarity with rolling statistics.
🔍 Anomaly Detection – Use statistical and ML methods to spot irregularities.
⏳ Time Series Decomposition – Separate components for deeper analysis.
🤖 Predictive Modeling – Build forecasting models (e.g., ARIMA, Prophet, LSTM).
